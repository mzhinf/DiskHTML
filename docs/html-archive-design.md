# HTML 快照与目录比较设计

## 目标与责任边界

用户交付物是可离线打开的单个 HTML：

- 快照：扫描目录，生成 `.html` 和同名 SQLite 索引；
- 比较：选择 HTML 快照中的历史目录，与本机任意目录比较，生成同样布局的 HTML；
- 重渲染：从 SQLite 生成当前模板版本 HTML，不重新扫描。

DiskHTML.exe 是生成器，不渲染最终快照内容；浏览器中的 HTML 是查看器，不静默枚举任意本机目录。

## 分层设计

~~~text
本机目录
  → Scanner：枚举、SHA-256、有界并发
  → SQLite：事务写入和长期索引
  → HTML renderer：内联数据、CSS、JavaScript、SVG
  → 单文件离线快照

基准 HTML 中选定目录 + 本机目录
  → 重定根 + 当前目录扫描
  → 相对路径归并 + SHA-256 判定
  → 与快照相同布局、增加状态列的离线比较 HTML
~~~

浏览器安全模型不允许本地 HTML 按任意输入路径扫描磁盘，也不能可靠获得全部创建时间和重解析点语义。因此完整比较必须由 EXE 扫描并生成报告。

## 目录选择与比较语义

快照保存完整文件和目录清单。EXE 的“选择快照内目录”对话框允许根目录和任意子目录：

1. 保留该目录及其后代；
2. 移除选中目录前缀，使其成为基准根；
3. 扫描本机待检查目录，使其成为当前根；
4. 使用大小写无关的规范化相对路径对齐；
5. 以 SHA-256 和有效状态产生 `MATCH/CHANGED/ADDED/MISSING/ERROR`。

因此历史 `资料/照片` 可与任意盘符、任意名称的本机目录比较。

## HTML 可视化契约

- 顶部显示快照名称、文件/目录/Hash 数、生成时间、可用磁盘信息、搜索和设置入口；
- 主体采用左侧固定宽度目录树、右侧高密度文件表；两侧在各自区域滚动；
- 文件表显示 Name、Size、Modified，并可开启 Created、SHA-256；比较报告增加 Status；
- Name 前使用内联 Lucide 文件/文件夹 SVG，树中用箭头和打开/关闭文件夹 SVG；
- 面包屑和文件夹行可导航，支持返回父目录；
- 搜索只按真实关键词匹配，结果在同一列表中展示并高亮；
- 列支持排序，长名称省略，SHA-256 不换行；
- 比对状态使用不同颜色，差异后代使父目录显示差异标记；
- 底部状态栏显示当前目录文件夹数、文件数和总大小，并支持导出当前视图；
- 所有资源内联，不使用 CDN，保留 `file:///` 离线打开能力。

## 浏览器内直接比较的边界

静态页面可以让用户显式选择小目录并用 Web Crypto 计算摘要，但无法提供与 EXE 相同的路径、创建时间、重解析点、超大目录和可恢复扫描语义。因此浏览器内直接比较不作为当前正式功能；正式报告由 EXE 生成。

## EXE 功能范围

默认界面只包含：

1. 生成目录快照；
2. 生成比对报告；
3. 从 SQLite 生成。

暂停、继续和取消只在任务运行时显示。新建项目、扫描配置页、旧式任务列表、两份 HTML 默认比较和目录式报告查看器不属于默认 EXE。

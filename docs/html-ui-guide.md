# 离线快照页面使用指南

DiskHTML 快照和比较报告均为单文件离线 HTML；双击即可在浏览器中打开，不会访问网络。

## 页面布局

- 顶部显示快照名称、文件与目录统计、Hash 统计、搜索框、中文/English 切换按钮和设置入口。
- 左侧为固定宽度的可展开目录树；单击文件夹会在右侧打开该目录。
- 右侧为文件列表，面包屑可直接返回任意父目录。
- 底部状态栏显示当前视图的文件夹数、文件数与总大小，并可导出当前视图。

## 页面语言

页面右上角的“English / 中文”按钮可在浏览器内切换界面语言。切换会立即刷新标题、搜索提示、表头、详情、状态栏、盘符设置说明和 CSV 导出列名；语言偏好仅保存在当前浏览器本机，不会修改快照数据、Hash 或文件树。
## 列表、搜索与详情

默认列表显示 `Name`、`Size`、`Modified`。点击“详细信息”后会额外显示 `Created`、摘要和具体算法。采样算法会同时显示快速预检提示，不能解释为完整内容一致。点击表头可按对应列升序或降序排列。

在右上角输入关键字会在同一列表区域显示全局搜索结果，匹配的文件名以黄色高亮，并增加 `Folder` 列显示所在目录。点击文件行会在列表下方显示完整元数据。

点击“导出当前视图”会下载 UTF-8 CSV，内容与当前搜索、排序和详细列状态一致。

## 比较报告与盘符切换

比较报告沿用相同的目录树与列表，仅增加“状态”列。存在不同文件的目录会显示红点。

“设置”中的盘符选择用于移动硬盘盘符变化后的本机路径显示；页面保留原始相对路径，Windows 会按当前软链接目标解析路径。
